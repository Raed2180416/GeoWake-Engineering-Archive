# Historical development demo

[Play the 112-second narrated video](GeoWake-demo.mp4).

This clip is supplied for review, outside the proposed model-training grant.
No training license to the third-party map imagery displayed in it is offered.

The original recording is a development simulation, not a field trial or proof
of correspondence to the final source revision. It was digitally silent; the
new voice explains visible actions and adds no purported app-alarm audio.
Narration uses local Kokoro-82M with stock af_heart (Apache-2.0 model/library),
not a cloned personal voice. Google attribution remains visible. Private
system panels and separate mock-location address/coordinate controls were cut.

The source video remains private and unchanged. Supplied captions and script
explain the edited clip. Codec/decoding, timing, finite audio samples and
loudness were checked; no independent perceptual listening approval is claimed.
Underground research is narration context, not visually validated by this clip.
